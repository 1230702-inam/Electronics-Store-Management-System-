# Electronics Store Management System

JavaFX desktop application for managing an electronics store, including products, customers, orders, payments, returns, warranties, and sales reports.

## Technology
- Java and JavaFX
- MySQL via JDBC
- Eclipse project

## Database configuration
Set environment variables `DB_USER` (defaults to `root`) and `DB_PASSWORD` before launching the application. The expected local database is `electronic_store` on port 3306.

**Note:** A MySQL schema and appropriate JavaFX/MySQL Connector/J dependencies are required to run the application.
